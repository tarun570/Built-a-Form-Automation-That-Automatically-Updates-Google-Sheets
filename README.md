# 🚀 Built a Form Automation That Automatically Updates Google Sheets

I created a simple but powerful automation where form submissions are directly appended or updated in Google Sheets — no manual data entry required.

📝 Workflow:
On Form Submission → 📊 Append / Update Row in Google Sheets

🔧 What this automation does:

Captures form data in real time

Automatically appends new rows or updates existing records

Keeps Google Sheets always up to date

Eliminates manual copy-paste work

🎯 Use cases:

Lead collection forms

Student or user registrations

Contact & inquiry forms

Internal data tracking systems
